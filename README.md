
# 🧠 Project Overview

This project analyzes a real-world **bank loan dataset** to identify factors that influence loan defaults.  
The analysis includes data cleaning, exploratory data analysis (EDA), visualization, and insights to support **data-driven lending strategies**.

---

## 🎯 Objectives
- Explore borrower demographics and financial indicators affecting loan defaults  
- Identify high-risk patterns to assist lenders in risk assessment  
- Visualize default trends by income, credit scores, loan amounts, and repayment history  
- Provide actionable insights for better loan approval policies  

---

## 📊 Key Insights
- **High revolving balance** and **high debt-to-income ratios** are strong indicators of default risk  
- **Poor credit scores** are consistently linked with higher loan default probability  
- Borrowers with **large loan amounts** show higher delinquency rates  
- Demographic segments show varying repayment behaviors  

---

## 🛠️ Approach
- **Data Preparation:** Cleaned and transformed raw dataset in Excel  
- **EDA (Exploratory Data Analysis):** Identified trends in defaults using demographic and financial factors  
- **Visualization:** Built interactive Tableau dashboards for deeper exploration  
- **Insights & Recommendations:** Highlighted high-risk groups and provided strategies to reduce defaults
