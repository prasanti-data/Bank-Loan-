### 🧠 Project Highlight: Bank Loan Default Analysis
- Explored a real-world bank loan dataset to identify key factors influencing loan defaults.
- Cleaned and transformed data in Excel to prepare it for analysis.
- Created interactive Tableau dashboards to visualize default trends by demographics, income, credit scores, loan amounts, and repayment history.
- Identified high-risk patterns such as high revolving balance, high debt-to-income ratios, and poor credit scores.
- Presented insights through visual storytelling to support data-driven lending strategies.
